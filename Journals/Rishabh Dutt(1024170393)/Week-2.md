# Week 2 Project Journal — Distributed Performance Testing Platform

## Sprint Planning & Dashboard Wireframing

## Objective for the Week

The objective of Week 2 was to begin UI planning for Sprint 1, outline dashboard requirements based on the project proposal, sketch initial wireframes, and research charting libraries suitable for displaying performance data during test execution.

## Day 2 — Dashboard Wireframing

- Sketched preliminary layouts for the proposed real-time test dashboard.

- Researched open-source frontend charting libraries suitable for displaying performance metrics.

- Participated in the weekly team review to summarise progress, discuss outstanding requirements, and identify priorities for the next week.
